Lee una playlist o álbum de YouTube Music, te muestra qué canciones ya tenés y te deja crear la playlist local o bajar solo las que faltan.
¿Qué se puede y qué no con YouTube Music?

YouTube Music no tiene una API pública oficial para tu biblioteca personal (me gusta, playlists). petalwave usa tu propia sesión (cookies.txt) con yt-dlp para leer lo mismo que ves en tu cuenta: nombres, artistas, álbumes y portadas.

No esquiva DRM ni contenido restringido: si algo no está disponible para tu cuenta, no se descarga. La alternativa oficial sería la YouTube Data API v3 con OAuth, que exige registrar una app en Google Cloud y no da acceso a los "me gusta" de YouTube Music.
